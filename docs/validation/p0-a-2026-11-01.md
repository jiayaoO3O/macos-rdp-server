## 命令与结果

```sh
make check
make test-protocol
```

- `make check`：`go test -race ./...` 与 `go vet ./...` 通过。编译时只有 FreeRDP
  头文件产生的两条上游弃用声明警告。
- `make test-protocol`：7 个用例全部通过，耗时 18.121 秒。测试使用随机 loopback
  端口、临时自签名证书和随机独立密码，结束后回收 worker 与临时目录。

协议测试实际覆盖：

| 用例 | 结果 | 说明 |
| --- | --- | --- |
| `test_01_bitmap_input_and_reconnect` | 通过 | 连续两次连接均收到 800×600 位图并通过键鼠得到回显；断开后可重连 |
| `test_01b_account_spellings` | 通过 | `TestUser/macrdp`、空域、`MACRDP\testuser` 规范化后匹配同一账号 |
| `test_02_wrong_password_unknown_user_and_domain` | 通过 | 错误密码、未知账号、`EVIL` 域均失败且不出现测试画面 |
| `test_03_nla_required` | 通过 | 仅 TLS、不带 NLA 的连接被拒绝 |
| `test_04_single_connection` | 通过 | 首个连接持租约时第二个连接被拒绝；释放后可重连 |
| `test_05_half_open_handshake_expires` | 通过 | 建 TCP 后不发送握手数据的连接在约 15 秒后被关闭 |
| `test_06_disabled_account` | 通过 | 配置禁用账号后，正确密码也被拒绝 |

这些是 FreeRDP 客户端探针结果，不能替代 Windows App 或 mstsc 验收。

## 本次发现并修复的缺陷

首次运行时 `test_05` 失败：半开连接在 18 秒客户端超时后仍未收到 EOF。

原因：监听线程的超时看门狗调用 `shutdown(peer->sockfd, SHUT_RDWR)`，但
`peer->sockfd` 在 `peer->Initialize()` 把 socket 所有权交给 transport 后已被
FreeRDP 置为 -1，看门狗实际是空操作。

修复：把截止时间检查移到 peer 自己的事件循环，在每次 250 ms 唤醒后比较看门狗
共享的 deadline，超时即退出循环并走正常断开/释放路径；删除无效的监听线程
shutdown 代码。回归用例即 `test_05`。

后续独立审计发现，此修复仍无法中止 `CheckFileDescriptor()` 内部停滞的 TLS 握手。
之后通过 duplicate socket + 独立 listener watchdog 补上取消路径，并新增
X.224 后不发送 TLS ClientHello 的回归测试。完整修复和最新验证结果见
[审计修复记录](audit-remediation-2026-11-01.md)；本节保留当时的阶段记录。

## 后续 Windows App 复核（2026-11-01）

- 本机 Microsoft Windows App 11.4.4 曾以错误码 `0x510d` 断开。Worker 日志显示
  至少一次连接完成认证（`event=authorized`），因此不是账号密码错误。
- macOS 统一日志记录 `size too large for internal buffer`、`Bitmap Decompression
  Failed` 和 `Disconnect for security`。探针进一步发现服务端测试画面发出 24 bpp
  位图，但会话声明为 32 bpp。
- 改为 32 bpp、降低图块高度后，Windows App 仍报告位图解码失败；改为 24 bpp 后也未
  解决。统一日志显示连接完成激活后，客户端因 `BD_DecompressBitmap failed` 主动断开。
- 当前原型改用 FreeRDP Planar 压缩编码，32 bpp、64×64 图块；探针断言压缩标志、位深
  和单块长度不超过 32 KiB。超时回归测试在专用环境变量下生成高熵帧，保持背压覆盖。
- 当前代码 `make check`、`make test-protocol`（10/10）通过。随后在测试机 Windows App
  中成功连接并看到绿色、黄色、深绿色、红色四块测试画面；画面未铺满较大的客户端
  窗口，与 RDP 配置固定 800×600 一致。按键后移动鼠标，色块产生预期的轻微变化，
  证明该客户端上的测试输入回显可用；这不是 Mac 桌面采集或实际 macOS 输入。
- Windows App 的断线重连和第二连接拒绝仍待人工验收。
